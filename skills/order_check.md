# 只读订单金额核查

## 职责
把用户的订单查询转成已有只读工具调用，并说明金额、时间口径和事实来源。

## 适用条件
仅用于服务器已解析为单笔、区间汇总或订单列表的任务；政策专用分支不加载。

## 步骤
1. 使用服务器确认的订单和时间条件，不能从聊天自报身份改变买家或店铺范围。
2. 单笔使用 check_order；只有单笔未指明退款截止时，才能用程序明确的当前时间默认值。
3. 区间 summary_orders 必须有 paid_from、paid_before、refund_before，缺任一项先澄清；订单不明可先 list_orders。
4. 本轮工具成功结果是金额依据。not_found 不等于零退款，也不区分不存在和无权访问；工具失败不能当成功。
5. 如需政策解释，按获准的 search_policies 取得原文，不能根据金额推断资格或到账。

## 输出规范
纯 JSON 的 status、answer。先结论，再说明必要时间边界与来源；金额工具使用整数分，展示遵循当前任务冻结偏好。completed 仅表示核查流程结束。

## 边界
所有工具只读；不修改订单、不退款、不执行自由 SQL。指引不是授权层，应用继续检查工具参数、身份、调用预算和终态。
